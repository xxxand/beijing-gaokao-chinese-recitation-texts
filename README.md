# 北京高考语文背诵篇目

是编辑北京高考语文背诵篇目，录为 Markdown 之文，分诗、文二部，以便讽诵检索。

## 篇目

诗三十二首，文十八篇，都五十篇。诗自《无衣》《静女》而下，讫于唐宋近体；文则经史子集，兼收并蓄。

## 目录结构

```
.
├── docs/
│   ├── poems/      # 诗三十二首
│   └── prose/      # 文十八篇
├── poems.txt       # 诗歌初文
└── prose.txt       # 散文初文
```

## 体例

一题一档，各为 `.md`。档名与题相合，其有“节选”“其一”诸目者，附于题后，例用全角括号，如 `离骚（节选）.md`。

每篇首书题，次署“〔朝代〕作者”，而后正文；句读分行，悉循旧本。

```markdown
# 短歌行

## 〔东汉〕曹操

对酒当歌，人生几何！
```
