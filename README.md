# 北京高考语文背诵篇目整理

本项目将北京高考语文背诵篇目整理为 Markdown 格式，便于阅读、检索和学习。

## 目录结构

```
.
├── docs/
│   ├── poems/      # 诗歌篇目（32首）
│   └── prose/      # 散文篇目（18篇）
├── poems.txt       # 原始诗歌文本
└── prose.txt       # 原始散文文本
```

## 文件格式

- 每个篇目单独一个 `.md` 文件
- 文件名与标题一致，包含“节选”等标注（如 `离骚(节选).md`）
- Markdown 结构：
  ```
  # 标题
  
  ## 〔朝代〕作者
  
  正文内容（保留原始断行）
  ```

## 使用说明

- 直接浏览 `docs/poems` 和 `docs/prose` 目录查看具体篇目
- 支持 Markdown 的阅读器（如 VS Code、Typora）可获得最佳阅读体验
- 文件可直接用于背诵、复习或制作学习卡片
